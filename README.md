# ক্রিপ্টো আপডেট: ২১ নভেম্বর ২০২৬ (শনিবার)

**দাম:** বিটকয়েন প্রায় $৫৮,০০০ (২৪ ঘণ্টায় ৬% কম), ইথেরিয়াম প্রায় $১,৬৫০ (৫.৬% কম)। সকালের দিকে বিটকয়েন একসময় $৫৫,১৩০-এ নেমেছিল, যা ২০২৪ সালের সেপ্টেম্বরের পর সর্বনিম্ন।

**কেন পড়ল:** AI-সংশ্লিষ্ট শেয়ারে বড় বিক্রির চাপ ক্রিপ্টোতেও ছড়িয়েছে। S&P 500 কমেছে ৩.৭%, নাসডাক ৫.৩%। এনভিডিয়া প্রায় ১৪% পড়েছে। এক দিনে $২.৪ বিলিয়নের বেশি ফিউচার পজিশন লিকুইডেট হয়েছে, বেশিরভাগই লং।

**ETF ও সেন্টিমেন্ট:** শুক্রবার মার্কিন বিটকয়েন ফান্ড থেকে প্রায় $১২৪.৫ মিলিয়ন বেরিয়ে গেছে। ফিয়ার অ্যান্ড গ্রিড ইনডেক্স ১২ (এক্সট্রিম ফিয়ার)।

**লক্ষ্য রাখার মতো:** সাপোর্ট $৫৫,১৩০ ও $৫৪,৫৯২; রেজিস্ট্যান্স $৬০,০০০। বুধবার অক্টোবরের PCE মুদ্রাস্ফীতির তথ্য আসবে, আর ৯ ডিসেম্বর ফেডের সিদ্ধান্ত।

*তথ্যসূত্র: Ted Pillows-এর ২১ নভেম্বরের রিপোর্ট। বিভিন্ন সাইটে দামে সামান্য ফারাক থাকে। এটা বিনিয়োগ পরামর্শ নয়।*
