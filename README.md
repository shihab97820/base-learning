## Day 36 – Understanding Transaction Finality ⏱️

Today's learning focused on transaction confirmation and finality in Layer 2 systems.

I learned that transaction processing involves multiple stages, from submitting a transaction and receiving an initial confirmation to the broader settlement process connected with Ethereum. Understanding these stages is important for developers building applications that handle valuable assets or time-sensitive operations.

Learning about finality gave me a clearer view of what happens behind the scenes after a user clicks the confirm button in a wallet.
